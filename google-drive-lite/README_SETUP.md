# Cài Google Drive Lite

1. Tạo project mới tại Google Apps Script.
2. Copy `Code.gs` vào project.
3. Chạy `setupDia8Dragon()` và cấp quyền.
4. Mở bảng tính được tạo, lấy mã tại trang `HUONG_DAN`.
5. Deploy thành Web app: Execute as Me, access Anyone.
6. Copy URL `/exec` vào Dia8Dragon → Giáo viên → Đồng bộ.

Tài liệu đầy đủ: `docs/GOOGLE_DRIVE_LITE_2.1.md`.
