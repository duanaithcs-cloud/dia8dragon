# Dia8Dragon Mobile 1.8

- Mobile-first responsive layer for screens 320px and wider.
- Bottom navigation with safe-area support.
- Full-width bottom-sheet customization panel.
- Larger touch targets and 16px form inputs.
- Mobile drawer/modal constraints and horizontal table scrolling.
- Portrait and landscape adaptations.
- PWA manifest and service worker for HTTPS/localhost deployments.
- LAN server bound to all interfaces for phones on the same Wi-Fi.
- Uses the same AppState and backup format as desktop 1.7.2.
