# Windows portable launcher

`build_launcher.py` tao launcher PE64 GUI `Dia8Dragon.exe` de goi `START_APP.bat` trong cung thu muc.
Launcher khong chua hoc lieu ben trong; ban phat hanh van la portable theo thu muc.

Kiem tra cau truc tren Linux:

```bash
file Dia8Dragon.exe
objdump -x Dia8Dragon.exe
```

Can kiem thu thuc te tren Windows 10/11 truoc khi phat hanh rong.
